## 📌 Overview

**NetPay Pro** is a cutting-edge, feature-rich billing and financial tracking dashboard application built with **Angular**. It is meticulously designed to help businesses and service providers seamlessly manage users, monitor payment recoveries, track total billed amounts versus collected revenue, and generate real-time financial statements through an intuitive, clean interface.

---

## ✨ Key Features

* **📊 Comprehensive Dashboard:** Instant high-level metrics including *Total Users*, *Total Collected*, *Total Billed*, and *Total Due* amounts.
* **📈 Visual Analytics:** Interactive charts comparing *Billed vs. Collected* financial trends over customized monthly periods.
* **👥 User Management:** Track active and pending user statuses efficiently.
* **💳 Advanced Billing Module:** Monitor pending and completed payments with status badges and automated tracking.
* **📄 Detailed Statements:** Generate and review financial ledger statements seamlessly.
* **⚙️ Customizable Settings:** Configure app preferences, dark/light display modes, and cloud syncing options.
* **🌙 Dark Mode Support:** Built-in UI toggle for comfortable day-and-night usage.

## ⚙️ Getting Started Locally

To run this project on your local machine, follow these steps:

### Prerequisites

Make sure you have the following installed on your system:

* [Node.js](https://nodejs.org/) (LTS version recommended)
* [Angular CLI](https://angular.io/cli) (`npm install -g @angular/cli`)

### Installation Steps

1. **Clone the repository:**
```bash
git clone [https://github.com/khdcoder/net-pay-pro.git](https://github.com/khdcoder/net-pay-pro.git)

```


2. **Navigate to the project directory:**
```bash
cd net-pay-pro

```


3. **Install dependencies:**
```bash
npm install

```


4. **Run the development server:**
```bash
ng serve

```


5. **Open your browser:**
Navigate to `http://localhost:4200/`. The app will automatically reload if you change any source files.
